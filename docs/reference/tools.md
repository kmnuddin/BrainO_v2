# Tools

Every tool BrainO registers, with its parameters. This page is generated from the code: the
parameter tables come from the same JSON schemas the AI agent sees (`braino tools schema`).

Tools that work on one recording take its `subject`, and `task`, `session` and `run` when the
subject has several recordings. *Decision* tools return a proposal that takes effect only once
a person approves it.
